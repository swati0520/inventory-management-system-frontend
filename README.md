# Stockroom Inventory Management System - Frontend

## Overview

Stockroom Inventory Management System is a responsive frontend application
developed to manage products and inventory through a clean and user-friendly
interface.

The frontend communicates with the backend REST APIs to perform authentication
and product management operations.

## Features

- User registration
- User login
- Logout functionality
- Protected dashboard routes
- Product listing
- Add new products
- Edit product details
- Delete products
- Search products by name or SKU
- Stock quantity tracking
- Automatic stock status display
- Form validation
- Success and error notifications
- Responsive user interface

## Tech Stack

- React
- Vite
- Ant Design
- Axios
- React Router
- JavaScript
